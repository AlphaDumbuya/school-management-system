Authentication\n\n- JWT-based authentication with automatic token refresh\n- Role-based access control (RBAC)\n- Protected routes\n- Login/Logout functionality\n- Session persistence\n\n**File**: `src/services/authService.ts`, `src/store/authStore.ts`\n\n### 2. Dashboard\n\n- Complete admin dashboard with KPI cards\n- Real-time alerts and notifications\n- Financial summary with collection tracking\n- Students at risk identification\n- System health monitoring\n\n**File**: `src/pages/AdminDashboard.tsx`\n\n### 3. Data Fetching\n\n- React Query for server state management\n- Automatic caching and invalidation\n- Retry logic and error handling\n- Loading states and error boundaries\n\n**File**: `src/hooks/useDashboard.ts`\n\n### 4. State Management\n\n- Zustand for global state (auth, preferences)\n- React Query for server state\n- Local component state with hooks\n\n**Files**: `src/store/authStore.ts`, `src/store/dashboardStore.ts`\n\n### 5. API Integration\n\n- Axios-based HTTP client with interceptors\n- Automatic auth token injection\n- Token refresh on 401 responses\n- Centralized error handling\n\n**File**: `src/lib/apiClient.ts`\n\n### 6. UI Components\n\n- KPI Cards with trend indicators\n- Alerts card with severity levels\n- Chart cards with loading states\n- Responsive layout with Tailwind CSS\n- Recharts for data visualization\n\n**Files**: `src/components/`\n\n### 7. Responsive Design\n\n- Mobile-first approach\n- Tablet and desktop optimization\n- Sidebar collapses on mobile\n- Touch-friendly interfaces\n\n---\n\n## API Integration\n\n### Authentication Endpoints\n\n```typescript\n// Login\nPOST /api/v1/auth/login\n{\n  email: string\n  password: string\n}\n\n// Get current user\nGET /api/v1/auth/me\n\n// Refresh token\nPOST /api/v1/auth/refresh\n{\n  refreshToken: string\n}\n\n// Logout\nPOST /api/v1/auth/logout\n```\n\n### Dashboard Endpoints\n\n```typescript\n// Get complete dashboard\nGET /api/v1/dashboards/admin/complete\n\n// Get metrics\nGET /api/v1/dashboards/admin/metrics\n\n// Get financial summary\nGET /api/v1/dashboards/admin/financial-summary\n\n// Get alerts\nGET /api/v1/dashboards/admin/alerts\n\n// Get charts\nGET /api/v1/dashboards/admin/chart/academic-performance\nGET /api/v1/dashboards/admin/chart/attendance-trend\nGET /api/v1/dashboards/admin/chart/fee-collection\nGET /api/v1/dashboards/admin/chart/student-distribution\n```\n\nSee `docs/PHASE_10_API_DOCUMENTATION.md` for complete API documentation.\n\n---\n\n## Custom Hooks\n\n### useAuth\n\n```typescript\nconst { user, isAuthenticated, isLoading, error, login, logout, hasRole, canAccess } = useAuth();\n\n// Check if user can access\nif (!canAccess(['admin', 'principal'])) {\n  // Redirect or show attendance, feeCollection, distribution } = charts;\n```\n\n---\n\n## State Management\n\n### Auth Store (Zustand)\n\n```typescript\nimport useAuthStore from '@store/authStore';\n\nconst { user,
