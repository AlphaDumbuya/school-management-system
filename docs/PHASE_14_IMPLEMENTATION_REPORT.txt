API ENDPOINTS
================================================================================

IMPORT ENDPOINTS:

POST /api/v1/import/students
  Query Parameters:
    - skipDuplicates (boolean)
    - duplicateStrategy (keep-first|keep-last|merge)
    - validateEnrollment (boolean)
  Response:
    {
      "totalProcessed": number,
      "successful": number,
      "failed": number,
      "duplicates": number,
      "skipped": number,
      "errors": [ImportError],
      "warnings": [string],
      "report": string
    }
